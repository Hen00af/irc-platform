R Relay

HOW TO USE

このサイトでできること

Relay はブラウザから IRC を使うチャットと、それを動かしている C++98 製 HTTP サーバの挙動を確かめられる場所です。公開しているページと エンドポイントを用途ごとにまとめました。

1. チャットする

このサイトの主機能です。アカウント登録はいりません。

ブラウザIRCチャット

/chat/

ニックネームとチャンネル名を入れるだけで参加できます。参加者一覧、 入退室の通知、直近50件の履歴の再生に対応します。

使い方と入力ルール

Enter で送信 / Shift + Enter で改行
  • ニックネームは英字始まりで最大9文字
  • チャンネルは # 始まりで2〜50文字
  • 1メッセージは420バイトまで
  • 5秒間に12操作を超えると一時的に制限されます
  • ヘッダーの Change channel / Change nick で部屋と名前を変更
履歴はメモリ上だけです。 チャンネルごとに最大100件を保持し、参加時に最新50件を再生しますが、 サーバが再起動すると消えます。保存用のデータベースはありません。

2. サーバの動きを見る

HTTPサーバの状態を計測・確認するページです。

コントロールプレーン

/admin/

チャット・ゲートウェイ・IRC の接続先一覧、各エンドポイントの応答 コードと所要時間の測定、負荷生成（localhost のみ有効）、成功率・ スループット・中央値・P95 の表示。

HTTPサーバのヘルスチェック

/health/

Webserv が応答していれば ok を返します。

ゲートウェイのヘルスチェック

/gateway/health

WebSocket ゲートウェイと接続先の IRC を JSON で返します。単一ポート 構成で公開している環境で利用できます。

3. ファイルを置く・消す

静的配信、ディレクトリ一覧、アップロード、削除を試せます。

アップロード

GET / POST / DELETE — /upload/

POST したファイルが保存され、一覧に追加されます。1リクエストの 上限は10MBです。DELETE で個別に削除できます。

ファイル一覧

GET / DELETE — /files/

ディレクトリの自動一覧表示（autoindex）を確認できます。中身が空の 場合は何も並びません。

コマンドラインからも試せます。
curl -F "file=@sample.txt" <このサイトのURL>/upload/

4. CGI の挙動を確かめる

Python と PHP のスクリプトをサーバ側で実行します。正常系だけでなく、 リダイレクト・任意ステータス・異常終了・時間切れも試せます。

エンドポイント 内容 応答
hello.py Python による最小の CGI 応答 200
hello.php PHP-CGI による最小の CGI 応答 200
echo.py?name=relay メソッド、クエリ、接続元アドレス、リクエストURIを返す 200
form.py?name=alice クエリと POST ボディをそのまま返す 200
cookie.py CGI から Set-Cookie を発行する 200
session.py セッションIDを発行し、2回目以降は同じIDを返す 200
redirect.py CGI からトップページへリダイレクトする 302
status.py?code=201 指定したステータスコードを返す（200〜599） 任意
error.py 意図的に失敗するスクリプト。500 の扱いを確認する 500
slow.py?seconds=2 指定秒数だけ停止する。制限時間を超えると打ち切られる 200 / 504

5. エラーページ

存在しないパスには専用の404ページを返します。

404 を見る

/this-path-does-not-exist

設定ファイルで指定したエラーページが表示されます。
Relay — C++98 の HTTP サーバ（Webserv）と IRC サーバ（ft_irc）を WebSocket ゲートウェイでつないだ構成です。接続先の一覧は コントロールプレーン で確認できます。
