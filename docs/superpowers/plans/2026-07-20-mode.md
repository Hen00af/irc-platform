# MODE Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** handleMode を実装し、Channel MODE(照会 + i/t/k/o/l 変更)を完成させる。これで全 14 ハンドラが実装済みになる。

**Architecture:** MODE 固有の符号解析・引数消費・成功変更集約を `prd/handler/ServerMode.cpp` に実装。Task 1 で解析ループの骨格と引数不要 Mode(i/t)+ 照会 + 通知集約を作り、Task 2 で引数消費 Mode(k/o/l)と未知 Mode を足す。

**Tech Stack:** C++98、自前 TestRunner、make。

**Spec (必読・全文が要件):** `docs/superpowers/specs/2026-07-20-mode-design.md`
**設計書 (必読):** `docs/markdown/05_mode_detailed_design_ja.md` 全体、`docs/markdown/06_error_reply_detailed_design_ja.md` §8

## Global Constraints

- C++98 のみ。`-Wall -Wextra -Werror -std=c++98` で警告ゼロ
- 送信行は必ず `Reply::numeric()` / `Reply::command()` 経由。生の連結禁止
- Numeric 定数は namespace `Numeric`。本文は設計書06 §8 と完全一致
- 通知の Channel 名は表示名(`Channel::getName()`)、Map 検索は `findChannel`(内部で正規化)
- 権限エラー(442/482)時は Mode 文字列を一切解析せず状態を変更しない(設計書05 §15)
- 一部 Mode の失敗で後続 Mode の解析を止めない。成功変更 0 件なら MODE 通知を送らない
- コメントは既存スタイル(設計書 §番号引用の日本語ブロックコメント)
- テストは `tests/handler/mode/test_mode.cpp`(suite "mode"、`runModeTests()`)。ヘルパは channel_cmd テストと同形の dispatchLine / takeOutput / registerUser を置く
- 各タスク: テスト先書き → `make -C tests test` RED → 実装 → GREEN(全 PASS + `make -C prd re` 警告ゼロ)→ コミット(末尾 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`)

## 期待文字列例 (op=fd3/alice/127.0.0.1, username "u")

```
:ircserv.local 324 alice #c +t                       (新規 Channel 照会)
:ircserv.local 324 alice #c +itkl secret 10          (全 Mode 有効時)
:alice!u@127.0.0.1 MODE #c +i
:alice!u@127.0.0.1 MODE #c +it
:alice!u@127.0.0.1 MODE #c +kol secret bob 10
:alice!u@127.0.0.1 MODE #c +it-k
:ircserv.local 461 alice MODE :Not enough parameters
:ircserv.local 482 alice #c :You're not channel operator
:ircserv.local 472 alice m :is unknown mode char to me for #c
:ircserv.local 401 alice nosuch :No such nick/channel
:ircserv.local 441 alice bob #c :They aren't on that channel
```

(各行 + `\r\n`。421 は `:ircserv.local 421 alice <target> :Unknown command`)
